1. EXECUTIVE SUMMARY & ARCHITECTURE HIGHLIGHTS
================================================================================

`developer.arunpandian.online` is an enterprise-grade digital product studio and
portfolio built with React 19, TypeScript, Vite, Tailwind CSS 4, and Supabase.

Core Pillars:
• Full-Stack MERN & Next.js: High-concurrency SSR/SSG platforms.
• Autonomous AI Agents & RAG: LLM assistants with vector embeddings & memory.
• n8n Enterprise Automations: Automated workflows connecting 50+ webhooks/CRMs.
• Multi-Tenant SaaS Architecture: Organization isolation & Stripe billing.

Visual Design OS Rules:
• Contrast Hierarchy: Sleek dark hero banners and footers (`bg-[#09090b]` / `bg-black`),
  paired with crisp white body sections (`bg-white` with dark slate typography).
• Micro-Interactions: Smooth Lenis scroll momentum, animated badges, and active glowing indicators.
• Real-Time CMS: 100% editable through the Theme Studio with instant Supabase DB broadcast.

5. DATABASE SCHEMA, SUPABASE REALTIME SYNC & CMS LIFECYCLE
================================================================================

Table: `public.site_cms_data`
• `id`: UUID (Primary Key, default: `00000000-0000-0000-0000-000000000001`)
• `data`: JSONB (Complete site configuration document matching `SiteCMSData`)
• `updated_at`: TIMESTAMPTZ (Auto-updated via PostgreSQL trigger)

Real-Time Sync Lifecycle:
1. Studio Mutation: User edits input/toggle in `ThemeStudio.tsx`.
2. Instant State Update: `CMSContext` dispatches local state change.
3. Live Preview Broadcast: Connected `iframe` updates styles and content instantly.
4. Cloud Persistence: User clicks `Publish to Supabase` -> upsert to `site_cms_data`.
5. Realtime Subscription: All connected clients receive postgres_changes broadcast.
